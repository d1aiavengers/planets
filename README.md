# 🌌 Solar System Explorer

An interactive and responsive web-based astronomy experience that lets you explore the planets of our Solar System through an immersive space-themed interface. 🪐

## 🚀 About the Project

**Solar System Explorer** is a frontend project built using **HTML, CSS, and JavaScript**. It provides an interactive way to explore the eight major planets along with Pluto, presenting their characteristics, measurements, descriptions, and interesting facts.

The interface combines a dark cosmic design, animated visuals, interactive planet navigation, and detailed information panels to create an engaging educational experience.

The project includes information such as planetary distance from the Sun, diameter, day length, year length, temperature, number of moons, and interesting facts.

## ✨ Features

* 🌍 Explore **8 planets + Pluto**
* ☀️ Interactive Solar System visualisation
* 🪐 Dynamic planet selection
* 📊 Detailed planetary facts and statistics
* 🔭 Interactive planet information dialog
* ⌨️ Keyboard navigation using **← / →** arrow keys
* 🌌 Animated starfield background
* 💫 Animated Sun and planetary visuals
* 🪐 3D-style Saturn ring system
* 📱 Responsive design for desktop, tablet, and mobile
* ♿ Keyboard-accessible navigation
* 🎞️ Reduced-motion support for accessibility
* 🎨 Modern dark space-themed UI

## 🛠️ Technologies Used

* **HTML5** – Structure and semantic markup
* **CSS3** – Responsive design, animations, gradients, and 3D-style effects
* **JavaScript** – Planet data, navigation, interactions, and dynamic content
* **Google Fonts** – DM Sans & Space Grotesk

## ▶️ How to Run

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder.

3. Make sure the `assets` folder is present.

4. Open `index.html` in your browser.

No backend or database is required.

## 🎮 Controls

### Mouse / Touch

Select any planet from the navigation bar.

### Keyboard

* `←` Previous planet
* `→` Next planet
* `Home` First planet
* `End` Last planet
* `Enter` / `Space` Select focused controls

## 🎯 Project Goal

The goal of this project is to make learning about the Solar System more **interactive, visual, and accessible** instead of presenting astronomical information as static text.

## 📱 Responsive Experience

The interface adapts to different screen sizes, including desktop and mobile layouts. The navigation, planet visualization, information sections, and detail dialog adjust according to the available screen space.

## 🌟 Highlights

One of the main visual features is the **Saturn ring system**, which uses multiple layered elements and CSS 3D transformations to create a stronger sense of depth between the planet and its rings.
